# Phase 1.5: simplification before the archive

Date: 2026-09-03
Status: approved design (addendum to `2026-09-03-postgres-archive-daemon-design.md`)

## Why

Phase 1 ported the 4.5 code to Postgres and split the processes but kept the
shape of a small SQLite cache in front of a slow Exchange. Phase 2 makes the
Postgres store the archive of the whole mailbox, and the vector search that
comes with it makes several 4.5 subsystems redundant. Removing them first keeps
Phase 2 small. Decisions below were confirmed by the owner on 2026-09-03.

## Decisions

| Area | Decision |
|---|---|
| Mirror scope | Every mail folder is mirrored, with no time window. Excluded by well-known key: `drafts`, `junk`, `trash`, `outbox` (`EWS_MIRROR_EXCLUDE`, default `drafts,junk,trash,outbox`). `EWS_CACHE_FOLDERS` and `EWS_CACHE_WINDOW_DAYS` are removed. |
| Folder identity | `messages.folder` (a well-known key string) becomes `messages.folder_id` = the folder's EWS id. The `folders` table is the source for resolution: well-known alias → `folders.wk`, `f7` alias → aliaser → ews id, path → `folders.path`. Store queries that hard-coded `'inbox'`/`'sent'` use `folders.wk` sub-selects. Per-folder sync tokens are keyed `item:<folder ews_id>`. |
| Folder lifecycle | The hierarchy lane runs before item sync on every cycle. A folder that disappears from the hierarchy has its sync token dropped and its `live` messages deleted; archived rows stay. New folders are picked up on the next hierarchy pass. |
| Live search | The Exchange search path is deleted. `search_messages` answers only from the store: `query` is full-text over the mirror, freely combinable with the structured filters (the AQS exclusivity rule goes away). `folder` omitted means all mirrored folders; an excluded folder is a validation error. `fresh` is removed from `search_messages` and `get_thread`; it stays on `get_message` (attachment inventory, HTML), `list_folders` and `get_mailbox_overview` (live counts). |
| Learned signatures | `sender_sigs`, `trailing_block`, `SIG_MIN_HITS`, `strip_learned_signature` are removed. `bodyclean` quote and signature stripping stays. |
| Text normalisation | `normalize.py` and `messages.norm_text` are removed. Migration 002 creates `CREATE EXTENSION IF NOT EXISTS unaccent` and an immutable wrapper `ews.immutable_unaccent(text)` (`LANGUAGE sql IMMUTABLE PARALLEL SAFE`, body `SELECT public.unaccent('public.unaccent', $1)`), and regenerates `search_tsv` as `to_tsvector('simple', ews.immutable_unaccent(lower(coalesce(subject,'') || ' ' || coalesce(sender_name,'') || ' ' || coalesce(sender_email,'') || ' ' || coalesce(body_clean,''))))`. Queries use `to_tsquery('simple', ews.immutable_unaccent(lower(%s)))` with the prefix expression (`tok:* & tok2:*`) built in Python from `\w+` tokens. |
| Migration 002 | Because the mirror is rebuildable and nothing is archived yet, 002 truncates `messages` and `sync_state`, renames `folder` → `folder_id`, drops `norm_text`/`search_tsv`/`sender_sigs`, then adds the new generated column and index. `SCHEMA_VERSION = 2`. |
| Arabic in bodyclean | All Arabic patterns and bidi handling are removed from `bodyclean.py`; the tests that exercise them go with them. |
| Dead code | Everything in the 2026-09-03 dead-code inventory sections 1–3 is removed: `server.run_stdio`/`build_mcp_server`, `mint_token`, `_cache_folder_key`/`_cache_watermark`, `ToolError.http_status`, `ConnectionManager.is_warm`, `NullAliaser`, `CacheStore.purge`/`close`, `_resolve_ids` alias, the `mail_read` re-exports, `scripts/live_smoke.py`, the `/mcp` branch and `mount_mcp`/`streamable` parameters of `http.build_app` (default `tools_prefix` becomes `/v1/tools`), the duplicate "cache disabled" CI job. `_NullAudit` moves to `audit.py` as `NullAudit` so the MCP no longer imports the daemon module. `kind_for_key` stays (public helper). |
| Tests | One `FakeGateway` (records calls, optional scripted account, optional "raise on contact") and `make_row` live in `conftest.py`; every test builds contexts through `make_context`. Assertion strength must not drop. |
| Docs | SQLite, FTS5, Arabic, "700×", semantic-tier and v3/4.5 back-references are removed from code comments, `DESIGN.md`, `README.md`, `docs/API.md` prose (the generated sections follow the registry). The tool rename map and "removed from 4.5" paragraphs move to `CHANGELOG.md`. |

## Out of scope

Replacing aliases with serial ids (deferred). Any archive, embedding or deletion
work (Phase 2). Changing the safety gates, audit chain or upload flow.

## End state Phase 2 builds on

`messages(ews_id PK, changekey, folder_id, conversation_id, sender_*, to_json,
subject, date_ts, date_iso, is_read, has_attachments, importance,
categories_json, body_clean, internet_message_id, archive_state, archived_at,
verified_at, deleted_at, mime_sha256, mime_path, embedded_at, search_tsv)`;
`folders(ews_id PK, name, path, wk, total, unread, children)`; `events`,
`tasks`, `sync_state`, `aliases`, `alias_counters`, `meta`,
`schema_migrations`. All mail folders except the excluded four are mirrored in
full. The daemon serves live reads only for `get_message(fresh=true)`,
`get_attachment`, `list_folders(fresh=true)`, `get_mailbox_overview(fresh=true)`,
calendar, people, tasks and all writes.
